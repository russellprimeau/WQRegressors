# Model Quality Matrix: Metrics and Statistical Analysis

This document describes the metrics, statistical tests, and evidence scoring system displayed in the **`summary_model_quality_matrix`** figure generated by `z1_FeaturePostProcess.py`. The matrix is a per-target heatmap that summarizes model accuracy, precision, reliability, and statistical support for each water quality target variable. Columns are divided into two groups: **descriptive performance metrics** (left) and **gate-evaluated statistical evidence metrics** (right).

---

## 1. Descriptive Performance Metrics

### 1.1 Test Sample Count

The number of independent evaluation segments (raw test samples) available for the target. This provides context for interpreting statistical power: targets with very few test samples may produce unreliable test results.

### 1.2 Best Model

A categorical label indicating which model type (XGB, Transformer, or GP) achieved the best performance for this target. Displayed with a color-coded background; not numerically scored.

### 1.3 Coefficient of Determination ($R^2$)

Measures the proportion of variance in the observed targets explained by the model predictions.

$$R^2 = 1 - \frac{SS_{\text{res}}}{SS_{\text{tot}}} = 1 - \frac{\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}{\sum_{i=1}^{n}(y_i - \bar{y})^2}$$

where $y_i$ are the observed values, $\hat{y}_i$ are the predicted values, and $\bar{y}$ is the mean of the observed values.

**Interpretation:** Values near 1.0 indicate excellent explanatory power; values near 0 indicate the model performs no better than predicting the mean; negative values indicate the model is worse than predicting the mean.

### 1.4 Normalized RMSE (nRMSE)

The root mean squared error normalized by the standard deviation of the observed target values, making the error scale-free and comparable across targets with different units or magnitudes.

$$\text{nRMSE} = \frac{\text{RMSE}}{\sigma_y} = \frac{\sqrt{\frac{1}{n}\sum_{i=1}^{n}(y_i - \hat{y}_i)^2}}{\sqrt{\frac{1}{n-1}\sum_{i=1}^{n}(y_i - \bar{y})^2}}$$

**Interpretation:** Lower is better. Values below 1.0 indicate the model error is smaller than the natural variability of the target; values above 1.0 indicate the model adds noise rather than information.

### 1.5 Skill vs. Best Baselinef

The minimum forecast skill score across the three baseline methods (naive, seasonal, linear) described below. Skill quantifies the relative improvement of the model over a reference baseline in terms of RMSE.

$$\text{Skill}_b = 1 - \frac{\text{RMSE}_{\text{model}}}{\text{RMSE}_{\text{baseline}_b}}$$

The displayed value is:

$$\text{Skill}_{\min} = \min_{b \in \{\text{naive}, \text{seasonal}, \text{linear}\}} \text{Skill}_b$$

**Interpretation:** Positive values indicate the model outperforms all three baselines; zero means parity; negative values mean the model is worse than at least one baseline. Taking the minimum across baselines is a conservative measure: the model must beat every baseline to achieve a positive score.

#### 1.5.1 Naive (Persistence) Baseline

The naive baseline assumes that the most recently observed value persists unchanged into the forecast horizon. For each forecast sample, the last valid observation before a causal gap is carried forward across all forecast time steps.

Given a forecast starting at time $t_0$ and a causal gap of $\Delta_{\text{gap}}$ hours, the cutoff time is $t_c = t_0 - \Delta_{\text{gap}}$. The prediction for every forecast step $t \geq t_0$ is:

$$\hat{y}(t) = y(t^{*}), \quad t^{*} = \max\{t_k : t_k \leq t_c,\; y(t_k) \text{ is valid}\}$$

where $t^{*}$ is the timestamp of the last valid observation at or before the cutoff.

**Interpretation:** This is the simplest possible forecast — it captures no trend, seasonality, or dynamics. A model that cannot outperform persistence is adding no useful information beyond the current state.

#### 1.5.2 Seasonal Baseline

The seasonal baseline predicts each forecast time step as the mean of historically observed values at similar times of year and time of day, excluding the current year to prevent data leakage. Similarity is determined by a hierarchical windowing strategy that relaxes constraints until a sufficient sample ($\geq 3$ values) is found.

For a forecast at day-of-year $d$ and hour-of-day $h$, the prediction is computed from prior-year observations using the first matching tier:

$$\hat{y}(d, h) = \frac{1}{|\mathcal{W}|}\sum_{i \in \mathcal{W}} y_i$$

where $\mathcal{W}$ is the set of valid historical values matching the narrowest sufficient window tier:

| Tier | Day-of-year constraint | Hour-of-day constraint |
|------|----------------------|----------------------|
| 1 | $|d_i - d| \leq W_{\text{day,narrow}}$ (circular) | $|h_i - h| \leq W_{\text{diurnal}}$ |
| 2 | $|d_i - d| \leq W_{\text{day,narrow}}$ (circular) | none |
| 3 | $|d_i - d| \leq W_{\text{day,wide}}$ (circular) | none |
| 4 | all prior-year values | none |

Day-of-year distances are computed circularly: $\Delta d = \min(|d_i - d|,\; 365 - |d_i - d|)$. Default windows are $W_{\text{day,narrow}} = 4$, $W_{\text{day,wide}} = 15$, and $W_{\text{diurnal}} = 2$ hours.

**Interpretation:** This baseline captures recurring annual and diurnal patterns without modeling trends or covariate relationships. A model must outperform it to demonstrate that it captures dynamics beyond the dominant seasonal cycle.

#### 1.5.3 Linear Baseline

The linear baseline fits an ordinary least-squares line to recent history for each target variable independently and extrapolates it into the forecast horizon. The fitting window spans a configurable multiple of the sample length preceding the forecast start.

Given a fitting window $[t_{\text{start}},\; t_{\text{end}})$ containing $n \geq 2$ observations at times $\{t_1, \ldots, t_n\}$ with values $\{y_1, \ldots, y_n\}$, the model fits:

$$\hat{y}(t) = \hat{\beta}_0 + \hat{\beta}_1\,t$$

where $t$ is expressed in seconds relative to $t_{\text{start}}$, and the coefficients are obtained by ordinary least-squares regression:

$$\hat{\beta}_1 = \frac{\sum_{i=1}^{n}(t_i - \bar{t})(y_i - \bar{y})}{\sum_{i=1}^{n}(t_i - \bar{t})^2}, \qquad \hat{\beta}_0 = \bar{y} - \hat{\beta}_1\,\bar{t}$$

The fitting window end respects the causal gap: $t_{\text{end}} = t_0 - \Delta_{\text{gap}}$, and the fitting span is $t_{\text{end}} - t_{\text{start}} = \kappa \cdot L$ where $\kappa = 3.1$ is the fit scale factor and $L$ is the target's sample length in hours. If fewer than 2 observations fall within the fitting window, the method falls back to persistence (last valid value).

**Interpretation:** This baseline captures short-term linear trends in the data. A model that cannot outperform it has failed to extract information beyond a simple extrapolation of the recent trajectory.

### 1.6 Normalized Mean Prediction Interval Width (NMPIW)

Measures the sharpness (tightness) of the model's prediction intervals, normalized by the standard deviation of the observed targets. Prediction intervals are constructed as symmetric quantile-based intervals around the point prediction using the empirical distribution of absolute residuals.

Given a nominal coverage level $(1 - \alpha)$, let $q_{1-\alpha}$ be the $(1-\alpha)$-quantile of the absolute residuals $|y_i - \hat{y}_i|$. The prediction interval for sample $i$ is:

$$[\hat{y}_i - q_{1-\alpha},\;\hat{y}_i + q_{1-\alpha}]$$

The mean prediction interval width (MPIW) and its normalized form are:

$$\text{MPIW} = 2\,q_{1-\alpha}$$

$$\text{NMPIW} = \frac{\text{MPIW}}{\sigma_y}$$

**Interpretation:** Lower is better. A model with tight intervals that still maintain adequate coverage is preferred. This metric is only meaningful when read alongside the coverage gap.

## 2. Gate-Evaluated Statistical Evidence Metrics

These columns summarize the statistical evidence that the model genuinely outperforms each baseline. They are used as binary gates in the Evidence Score computation.

### 2.1 Coverage Gap (PICP $-$ Nominal)

The difference between the empirical prediction interval coverage probability (PICP) and the nominal coverage level.

$$\text{PICP} = \frac{1}{n}\sum_{i=1}^{n}\mathbf{1}\!\left[y_i \in [\hat{y}_i - q_{1-\alpha},\;\hat{y}_i + q_{1-\alpha}]\right]$$

$$\text{Coverage Gap} = \text{PICP} - (1 - \alpha)$$

**Interpretation:** Values near zero indicate well-calibrated intervals. Positive values indicate conservative (over-covering) intervals; negative values indicate under-coverage (intervals are too narrow to be trustworthy). This column is zero-centered in the heatmap coloring: values closer to zero receive better (greener) colors regardless of sign.

### 2.2 Minimum 95% Lower Confidence Bound of Skill

The 5th percentile of the bootstrap distribution of skill scores, taken as the minimum across all three baselines. This provides a conservative, uncertainty-aware estimate of model improvement.

Given $B$ bootstrap replicates, each yielding a skill estimate $\text{Skill}_b^{(j)}$ for baseline $b$ and replicate $j$:

$$\text{LCB}_{95\%}^{(b)} = \hat{Q}_{0.05}\!\left(\{\text{Skill}_b^{(j)}\}_{j=1}^{B}\right)$$

$$\text{LCB}_{95\%}^{\min} = \min_{b \in \{\text{naive}, \text{seasonal}, \text{linear}\}} \text{LCB}_{95\%}^{(b)}$$

The bootstrap resampling operates at the **group level** (independent temporal segments), not individual data points, to respect the dependence structure within segments. Two resampling modes are supported: **i.i.d.** (groups drawn with replacement) and **moving block** (contiguous blocks of groups drawn to preserve temporal ordering).

**Interpretation:** If this value is positive, the model outperforms all baselines even under pessimistic sampling variability. This is the primary gate for the Evidence Score.

### 2.3 Best False Discovery Rate Adjusted q-value

The minimum Benjamini-Hochberg adjusted p-value (q-value) across all statistical tests (Diebold-Mariano, Wilcoxon, Sign) and all baselines. The BH procedure controls the false discovery rate when testing multiple hypotheses simultaneously.

Given $m$ raw p-values $p_{(1)} \leq p_{(2)} \leq \cdots \leq p_{(m)}$ from all test-baseline combinations, the adjusted q-values are:

$$q_{(i)} = \min\!\left(\min_{j \geq i}\frac{p_{(j)} \cdot m}{j},\; 1\right)$$

with the constraint that $q_{(i)} \leq q_{(i+1)}$ (monotonicity enforced by processing from the largest rank downward).

**Interpretation:** Lower is better. A small q-value (e.g., $< 0.05$) indicates that the observed performance difference is unlikely to be a false discovery even after accounting for the multiplicity of tests. Falls back to the unadjusted p-value if q-values are unavailable.

### 2.4 Best p-value

The minimum unadjusted p-value across all statistical tests and baselines (shown only when finite values exist). Provided as a reference alongside the FDR-adjusted q-values.

### 2.5 Evidence Score

An integer score (0 to 5) summarizing how many independent lines of statistical evidence support the conclusion that the model outperforms a given baseline. The **overall** Evidence Score displayed in the matrix is the **minimum** across all baselines, ensuring the model must demonstrate consistent superiority.

## 3. Statistical Tests (used in gates and p/q-values)

### 3.1 Diebold-Mariano Test

Tests whether the mean squared error of the model differs significantly from that of a baseline. Operates on the group-aggregated MSE difference series $d_i = \text{MSE}_{\text{model},i} - \text{MSE}_{\text{baseline},i}$ for $i = 1, \ldots, n$ groups.

The test statistic uses a heteroskedasticity and autocorrelation consistent (HAC) variance estimator with Bartlett kernel weights:

$$\bar{d} = \frac{1}{n}\sum_{i=1}^{n} d_i$$

$$\hat{\gamma}_0 = \frac{1}{n}\sum_{i=1}^{n}(d_i - \bar{d})^2$$

$$\hat{\gamma}_k = \frac{1}{n}\sum_{i=k+1}^{n}(d_i - \bar{d})(d_{i-k} - \bar{d}), \quad k = 1, \ldots, K$$

$$\hat{\sigma}^2_{\text{HAC}} = \hat{\gamma}_0 + 2\sum_{k=1}^{K}\left(1 - \frac{k}{K+1}\right)\hat{\gamma}_k$$

$$\text{DM} = \frac{\bar{d}}{\sqrt{\hat{\sigma}^2_{\text{HAC}} / n}}$$

where $K$ is the maximum lag (configurable via `dm_max_lag`). Under the null hypothesis of equal predictive accuracy, $\text{DM} \sim \mathcal{N}(0, 1)$ asymptotically. A two-sided p-value is computed:

$$p = 2\left(1 - \Phi(|\text{DM}|)\right)$$

**Gate condition:** $p < \alpha_{\text{evidence}}$ **and** $\text{DM} < 0$ (model has lower MSE).

**Qualitative interpretation:** Tests whether the model achieves a statistically significant reduction in mean squared prediction error relative to the baseline, accounting for potential autocorrelation in the error series. The HAC variance estimator makes the test robust to serial dependence in forecast errors, which is common in time series data.

### 3.2 Wilcoxon Signed-Rank Test

A non-parametric test applied to the group-aggregated absolute error differences $d_i = |e_{\text{model},i}| - |e_{\text{baseline},i}|$. Tests whether the distribution of paired differences is symmetric about zero.

For $n$ non-zero differences, rank the $|d_i|$ and compute:

$$W = \sum_{i:\,d_i > 0} R_i$$

where $R_i$ is the rank of $|d_i|$ among all non-zero differences. The two-sided p-value tests $H_0$: the distribution of $d_i$ is symmetric around zero.

**Gate condition:** $p < \alpha_{\text{evidence}}$.

**Qualitative interpretation:** Unlike the DM test which focuses on squared errors, the Wilcoxon test evaluates whether the model tends to produce smaller absolute errors than the baseline across test groups. Being non-parametric, it makes no distributional assumptions and is robust to outliers and skewed error distributions.

### 3.3 Sign Test

The simplest non-parametric test, counting only the direction of improvement without regard to magnitude. Applied to the same absolute error differences as the Wilcoxon test.

Let $W^{+}$ be the number of groups where the model has strictly lower absolute error than the baseline, and $W^{-}$ the number where it has strictly higher error. Ties (zero differences) are excluded.

$$n = W^{+} + W^{-}$$

$$\text{Win Rate} = \frac{W^{+}}{n}$$

Under $H_0$ (equal performance), $W^{+} \sim \text{Binomial}(n, 0.5)$. The two-sided p-value is:

$$p = P\!\left(|W^{+} - n/2| \geq |w^{+}_{\text{obs}} - n/2|\;\middle|\;W^{+} \sim \text{Binom}(n, 0.5)\right)$$

computed via `scipy.stats.binomtest`.

**Gate condition:** $p < \alpha_{\text{evidence}}$ **and** $\text{Win Rate} > 0.5$ (model wins more often than it loses).

**Qualitative interpretation:** Answers the question "does the model beat the baseline more often than not?" without being influenced by the magnitude of wins or losses. This is the most conservative of the three tests — a model could have large wins and small losses yet still fail the sign test if it loses on a majority of groups.

## 4. Evidence Score Computation

For each baseline $b \in \{\text{naive}, \text{seasonal}, \text{linear}\}$, five binary gates are evaluated. Each gate that passes contributes 1 point to the per-baseline score:

| Gate | Symbol | Condition | What it checks |
|------|--------|-----------|----------------|
| Bootstrap LCB | $G_{\text{lcb}}$ | $\text{LCB}_{95\%}^{(b)} > 0$ | Conservative skill estimate is positive |
| Diebold-Mariano | $G_{\text{dm}}$ | $p_{\text{DM}} < \alpha$ and $\text{DM} < 0$ | Significant MSE reduction |
| Wilcoxon | $G_{\text{wilc}}$ | $p_{\text{Wilcoxon}} < \alpha$ | Significant absolute error reduction |
| Sign Test | $G_{\text{sign}}$ | $p_{\text{Sign}} < \alpha$ and Win Rate $> 0.5$ | Model wins majority of groups |
| Coverage | $G_{\text{cov}}$ | Coverage deficit $\leq \tau$ and deficit $\leq$ baseline deficit $+ \tau$ | Prediction intervals are adequately calibrated |

where $\alpha = \alpha_{\text{evidence}}$ (configurable significance level) and $\tau$ is the coverage tolerance.

The per-baseline score is:

$$S_b = G_{\text{lcb}}^{(b)} + G_{\text{dm}}^{(b)} + G_{\text{wilc}}^{(b)} + G_{\text{sign}}^{(b)} + G_{\text{cov}}^{(b)} \quad \in \{0, 1, 2, 3, 4, 5\}$$

The **overall Evidence Score** displayed in the matrix is:

$$S_{\text{overall}} = \min_{b \in \{\text{naive}, \text{seasonal}, \text{linear}\}} S_b$$

**Interpretation:** A score of 5 means the model passes every gate against every baseline — strong, multi-faceted evidence of genuine predictive skill. A score of 0 means the model fails to pass any gate against at least one baseline. Taking the minimum across baselines ensures the score reflects the weakest link: the model must demonstrate superiority over all reference methods, not just the easiest one to beat.

### Pre-requisite: Minimum Sample Gate

Before any per-baseline gates are evaluated, a minimum sample size check is applied: the number of raw evaluation samples must meet the threshold `evidence_min_raw_samples`. Additionally, a bootstrap probability gate requires that $P(\text{Skill} > 0) \geq$ `evidence_min_prob`. These serve as necessary conditions that filter out targets with insufficient data for meaningful statistical testing, but are not counted in the 0–5 score.

## 5. Heatmap Visualization

Each cell in the matrix is colored on a **Red-Yellow-Green** scale based on column-wise min-max normalization:

- **Higher-is-better** columns ($R^2$, Skill, LCB, Evidence Score, Test Sample Count): green = high, red = low.
- **Lower-is-better** columns (nRMSE, NMPIW, q-value, p-value): the scale is inverted so green = low, red = high.
- **Zero-centered** columns (Coverage Gap): colored by proximity to zero — green = near zero, red = large absolute deviation.

Rows are sorted by evidence tier (ascending), then by p-value (descending), then by q-value (descending), so the strongest models appear at the bottom and the weakest at the top.
